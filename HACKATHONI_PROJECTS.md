# HackaThoni 2026 projects

Public repos built at **HackaThoni**, the overnight solo hackathon on two houseboats in Alappuzha (21–22 Nov 2026, Devin × TinkerHub, with Sarvam and smallest.ai).

**Web version (search and filter):** https://claude.ai/artifact/8kJACw6a9PCq9Rd7fRpF2A

Winners first, then in the order the repos were created. Found by searching GitHub for repos created on the event night and reading each README. Times are IST.
